# C API + .NET Binding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a C FFI layer (`heeranjid-ffi`) exposing core type operations via a stable C ABI, and a .NET wrapper (`heeranjid-dotnet`) that calls into it via P/Invoke. Includes EF Core value converters and a SQL migration helper.

**Architecture:** `heeranjid-ffi` is a Rust `cdylib` crate that exposes `extern "C"` functions for HeerId/RanjId decoding, encoding, and string conversion. `cbindgen` auto-generates the C header. The .NET package uses P/Invoke to call these functions, wrapping them in idiomatic C# types. No database connections cross the FFI boundary — EF Core uses `HasDefaultValueSql` to call Postgres functions directly.

**Tech Stack:** Rust cdylib, cbindgen, .NET 8 LTS, C#, EF Core (optional), xUnit, NuGet

**Prerequisites:** Workspace restructure (from workspace-restructure plan) must be complete.

use std::cell::RefCell;
use std::ffi::{CStr, CString};
use std::os::raw::c_char;

thread_local! {
    static LAST_ERROR: RefCell<Option<CString>> = const { RefCell::new(None) };
}

fn set_last_error(msg: &str) {
    LAST_ERROR.with(|cell| {
        *cell.borrow_mut() = CString::new(msg).ok();
    });
}

/// Returns the last error message, or null if no error occurred.
/// The returned pointer is valid until the next FFI call on this thread.
#[unsafe(no_mangle)]
pub extern "C" fn heer_last_error() -> *const c_char {
    LAST_ERROR.with(|cell| {
        cell.borrow()
            .as_ref()
            .map_or(std::ptr::null(), |s| s.as_ptr())
    })
}

pub type HeerIdT = i64;

#[repr(C)]
pub struct RanjIdT {
    pub bytes: [u8; 16],
}

/// Decode a HeerId into its component parts.
/// Returns 0 on success, -1 on error.
#[unsafe(no_mangle)]
pub extern "C" fn heer_id_decode(
    id: HeerIdT,
    timestamp_ms: *mut i64,
    node_id: *mut i32,
    sequence: *mut i32,
) -> i32 {
    let hid = match heeranjid::HeerId::from_i64(id) {
        Ok(h) => h,
        Err(e) => {
            set_last_error(&e.to_string());
            return -1;
        }
    };
    let parts = hid.into_parts();
    unsafe {
        *timestamp_ms = parts.timestamp_ms as i64;
        *node_id = parts.node_id as i32;
        *sequence = parts.sequence as i32;
    }
    0
}

/// Convert a HeerId to its string representation.
/// Returns 0 on success, -1 if the buffer is too small.
#[unsafe(no_mangle)]
pub extern "C" fn heer_id_to_string(
    id: HeerIdT,
    buf: *mut c_char,
    buf_len: usize,
) -> i32 {
    let hid = match heeranjid::HeerId::from_i64(id) {
        Ok(h) => h,
        Err(e) => {
            set_last_error(&e.to_string());
            return -1;
        }
    };
    let s = hid.to_string();
    if s.len() + 1 > buf_len {
        set_last_error("buffer too small");
        return -1;
    }
    let c_str = CString::new(s).unwrap();
    unsafe {
        std::ptr::copy_nonoverlapping(c_str.as_ptr(), buf, c_str.as_bytes_with_nul().len());
    }
    0
}

/// Parse a HeerId from a string.
/// Returns 0 on success, -1 on error.
#[unsafe(no_mangle)]
pub extern "C" fn heer_id_from_string(
    s: *const c_char,
    out: *mut HeerIdT,
) -> i32 {
    let c_str = unsafe { CStr::from_ptr(s) };
    let str_slice = match c_str.to_str() {
        Ok(s) => s,
        Err(e) => {
            set_last_error(&e.to_string());
            return -1;
        }
    };
    let hid: heeranjid::HeerId = match str_slice.parse() {
        Ok(h) => h,
        Err(e) => {
            set_last_error(&e.to_string());
            return -1;
        }
    };
    unsafe {
        *out = hid.as_i64();
    }
    0
}

pub extern "C" fn ranj_id_decode(
    id: *const RanjIdT,
    timestamp_us: *mut i64,
    node_id: *mut i32,
    sequence: *mut i32,
) -> i32 {
    let bytes = unsafe { &(*id).bytes };
    let uuid = uuid::Uuid::from_bytes(*bytes);
    let rid = match heeranjid::RanjId::from_uuid(uuid) {
        Ok(r) => r,
        Err(e) => {
            set_last_error(&e.to_string());
            return -1;
        }
    };
    let parts = rid.into_parts();
    unsafe {
        *timestamp_us = parts.timestamp_micros as i64;
        *node_id = parts.node_id as i32;
        *sequence = parts.sequence as i32;
    }
    0
}

    id: *const RanjIdT,

using System.Text;

namespace HeeRanjID;

/// <summary>
/// A 64-bit time-ordered distributed identifier.
/// Stored as a Postgres BIGINT.
/// </summary>
public readonly struct HeerId : IEquatable<HeerId>, IComparable<HeerId>
{
    public long Value { get; }

    public HeerId(long value)
    {
        if (value < 0)
            throw new ArgumentOutOfRangeException(nameof(value), "HeerId must be non-negative");
        Value = value;
    }

    public long TimestampMs
    {
        get
        {
            NativeMethods.heer_id_decode(Value, out var ts, out _, out _);
            return ts;
        }
    }

    public int NodeId
    {
        get
        {
            NativeMethods.heer_id_decode(Value, out _, out var nid, out _);
            return nid;
        }
    }

    public int Sequence
    {
        get
        {
            NativeMethods.heer_id_decode(Value, out _, out _, out var seq);
            return seq;
        }
    }

    public DateTimeOffset Timestamp =>
        DateTimeOffset.UnixEpoch.AddMilliseconds(TimestampMs);

    public static HeerId Parse(string s)
    {
        var rc = NativeMethods.heer_id_from_string(s, out var result);
        if (rc != 0)
        {
            var err = NativeMethods.heer_last_error() ?? "unknown error";
            throw new FormatException($"Invalid HeerId: {err}");
        }
        return new HeerId(result);
    }

    public override string ToString()
    {
        var buf = new byte[32];
        var rc = NativeMethods.heer_id_to_string(Value, buf, (nuint)buf.Length);
        if (rc != 0)
            return Value.ToString();
        var len = Array.IndexOf(buf, (byte)0);
        return Encoding.UTF8.GetString(buf, 0, len >= 0 ? len : buf.Length);
    }

    public bool Equals(HeerId other) => Value == other.Value;
    public override bool Equals(object? obj) => obj is HeerId other && Equals(other);
    public override int GetHashCode() => Value.GetHashCode();
    public int CompareTo(HeerId other) => Value.CompareTo(other.Value);

    public static bool operator ==(HeerId left, HeerId right) => left.Equals(right);
    public static bool operator !=(HeerId left, HeerId right) => !left.Equals(right);
    public static bool operator <(HeerId left, HeerId right) => left.CompareTo(right) < 0;
    public static bool operator >(HeerId left, HeerId right) => left.CompareTo(right) > 0;
    public static bool operator <=(HeerId left, HeerId right) => left.CompareTo(right) <= 0;
    public static bool operator >=(HeerId left, HeerId right) => left.CompareTo(right) >= 0;

    public static implicit operator long(HeerId id) => id.Value;
}

```csharp
using System.Text;

namespace HeeRanjID;

/// <summary>
/// A 128-bit time-ordered distributed identifier (UUIDv7).
/// Stored as a Postgres UUID.
/// </summary>
public readonly struct RanjId : IEquatable<RanjId>
{
    private readonly RanjIdBytes _bytes;

    private RanjId(RanjIdBytes bytes)
    {
        _bytes = bytes;
    }

    public long TimestampMicros
    {
        get
        {
            NativeMethods.ranj_id_decode(in _bytes, out var ts, out _, out _);
            return ts;
        }
    }

    public int NodeId
    {
        get
        {
            NativeMethods.ranj_id_decode(in _bytes, out _, out var nid, out _);
            return nid;
        }
    }

    public int Sequence
    {
        get
        {
            NativeMethods.ranj_id_decode(in _bytes, out _, out _, out var seq);
            return seq;
        }
    }

    public DateTimeOffset Timestamp =>
        DateTimeOffset.UnixEpoch.AddMicroseconds(TimestampMicros);

    public Guid ToGuid() => new Guid(_bytes.Bytes, bigEndian: true);

    public static RanjId Parse(string s)
    {
        var rc = NativeMethods.ranj_id_from_string(s, out var result);
        if (rc != 0)
        {
            var err = NativeMethods.heer_last_error() ?? "unknown error";
            throw new FormatException($"Invalid RanjId: {err}");
        }
        return new RanjId(result);
    }

    public static RanjId FromGuid(Guid guid)
    {
        var bytes = new RanjIdBytes { Bytes = guid.ToByteArray(bigEndian: true) };
        // Validate it's a v7 UUID by trying to decode
        var rc = NativeMethods.ranj_id_decode(in bytes, out _, out _, out _);
        if (rc != 0)
        {
            var err = NativeMethods.heer_last_error() ?? "unknown error";
            throw new FormatException($"Invalid RanjId: {err}");
        }
        return new RanjId(bytes);
    }

    public override string ToString()
    {
        var buf = new byte[48];
        var rc = NativeMethods.ranj_id_to_string(in _bytes, buf, (nuint)buf.Length);
        if (rc != 0)
            return Convert.ToHexString(_bytes.Bytes);
        var len = Array.IndexOf(buf, (byte)0);
        return Encoding.UTF8.GetString(buf, 0, len >= 0 ? len : buf.Length);
    }

    public bool Equals(RanjId other) => _bytes.Bytes.AsSpan().SequenceEqual(other._bytes.Bytes);
    public override bool Equals(object? obj) => obj is RanjId other && Equals(other);
    public override int GetHashCode()
    {
        var hash = new HashCode();
        hash.AddBytes(_bytes.Bytes);
        return hash.ToHashCode();
    }

    public static bool operator ==(RanjId left, RanjId right) => left.Equals(right);
    public static bool operator !=(RanjId left, RanjId right) => !left.Equals(right);
}
```

using Microsoft.EntityFrameworkCore;

namespace HeeRanjID.EntityFramework;

public static class ModelBuilderExtensions

    /// <summary>
    /// Configures an entity property as a HeerId with database-generated default.
    /// </summary>
    public static void UseHeerId<TEntity>(
        this ModelBuilder builder,
        System.Linq.Expressions.Expression<Func<TEntity, HeerId>> propertyExpression)
        where TEntity : class

            .Property(propertyExpression)
            .HasConversion(new HeerIdValueConverter())

```csharp
using System.Reflection;
using System.Text;

namespace HeeRanjID;

/// <summary>
/// Helper to read the bundled HeeRanjID SQL scripts.
/// </summary>
public static class SqlHelper
{
    private static readonly Assembly Assembly = typeof(SqlHelper).Assembly;

    /// <summary>
    /// Returns the full SQL to install the HeeRanjID schema and functions.
    /// Execute this against your Postgres database before using HeeRanjID.
    /// </summary>
    public static string GetInstallSql()
    {
        var files = new[]
        {
            "schema.sql",
            "session.sql",
            "generate_heerid.sql",
            "generate_ranjid.sql",
        };

        var sb = new StringBuilder();
        foreach (var file in files)
        {
            sb.AppendLine(ReadEmbeddedSql(file));
        }
        return sb.ToString();
    }

    /// <summary>
    /// Returns the SQL to seed a default node (node_id=1).
    /// </summary>
    public static string GetSeedSql() => ReadEmbeddedSql("seed.sql");

    private static string ReadEmbeddedSql(string filename)
    {
        var resourceName = $"HeeRanjID.sql.{filename}";
        using var stream = Assembly.GetManifestResourceStream(resourceName)
            ?? throw new InvalidOperationException($"Embedded resource '{resourceName}' not found");
        using var reader = new StreamReader(stream);
        return reader.ReadToEnd();
    }
}
```
